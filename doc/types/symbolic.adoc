= Symbolic Expressions

== Symbolic Expressions

Emmy provides powerful support for symbolic mathematics through its generic operations and literal types. This section focuses on literal numbers and other symbolic objects, demonstrating how to use them effectively in Emmy's symbolic computation environment.

=== Literal Numbers

To work with symbolic expressions, first require the necessary namespaces:

[source, clojure]
----
(require '[emmy.env :as e])
----

Create a literal number using the `literal-number` function or simply use a Clojure symbol:

[source, clojure]
----
(e/literal-number 'a)
;; or simply
'a
----

Literal numbers behave like regular numbers but maintain their symbolic representation:

[source, clojure]
----
(e/kind 'a)
;;=>  :emmy.expression/numeric

(e/freeze 'a)
;;=>  a
----

=== Symbolic Arithmetic

Emmy's generic arithmetic functions automatically work with literal numbers:

[source, clojure]
----
(e/+ 'x 3)
;;=> (+ 3 x)

(e/sin (e/+ 'a 'b))
;;=> (sin (+ a b))
----

=== Building and Using Symbolic Functions

You can create functions using Emmy's generic operations and apply them to symbols:

[source, clojure]
----
(defn symbolic-square [x]
  (e/* x x))

(symbolic-square 'y)
;;=> (* y y)

;; Using Emmy's built-in functions
(e/cube 'z)
;;=> (expt z 3)
----

=== Derivatives and Symbolic Manipulation

Emmy's derivative operator `D` works seamlessly with symbolic expressions:

[source, clojure]
----
((e/D e/sin) 'x)
;;=> (cos x)

((e/D e/cube) 'y)
;;=> (* 3 (expt y 2))
----

=== Simplification and Pretty Printing

Use `simplify` to reduce complex expressions and `print-expression` for formatted output:

[source, clojure]
----
(e/simplify (e/+ (e/* 'x 'x) (e/* 'x 2)))
;;=> (+ (* 2 x) (expt x 2))

(e/print-expression (e/simplify ((e/D e/cube) 'x)))
;; 3 * x^2
----

=== Other Symbolic Objects

Emmy supports various symbolic mathematical objects:

[source, clojure]
----
(e/literal-vector 'v)
(e/literal-down-tuple 'd)
(e/literal-up-tuple 'u)
(e/literal-matrix 'M)
(e/literal-function 'f)
----

These can be used in expressions and manipulated symbolically:

[source, clojure]
----
(def f (e/literal-function 'f))
(f 'x)
;;=> (f x)

((e/D f) 'x)
;;=> ((D f) x)
----

=== Integration with Emmy's CAS

Symbolic expressions in Emmy integrate seamlessly with its Computer Algebra System (CAS). You can perform complex algebraic manipulations, solve equations, and more. For advanced usage, explore the `emmy.algebra` and `emmy.calculus` namespaces.

For further exploration of Emmy's symbolic capabilities, check out:

- The `emmy.polynomial` namespace for working with symbolic polynomials
- The `emmy.series` namespace for power series and Taylor expansions
- The `emmy.abstract.function` namespace for advanced function manipulation

Remember, most functions in `emmy.env` are designed to work with both numeric and symbolic inputs, allowing for flexible and powerful mathematical expressions.
